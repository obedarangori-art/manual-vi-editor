## Guardar y salir 
Es la acción de almacenar de forma permanente los cambios realizados en un archivo en el disco de almacenamiento y, de manera inmediata, cerrar el documento o la aplicación.

En Linux, las secuencias de teclas y comandos para guardar y salir varían según el editor que estés utilizando en la terminal:

1. Editor Vim / Vi
Para guardar y salir en Vim, primero presiona la tecla Esc (para asegurarte de estar en modo normal) y luego escribe cualquiera de las siguientes opciones:

:wq + Enter: Guarda los cambios (write) y sale (quit).

ZZ (en mayúsculas): Guarda y sale de forma rápida sin necesidad de presionar Enter.

:q! + Enter: Sale sin guardar ningún cambio (forzado).

2. Editor Nano
Ctrl + O, luego Enter: Guarda los cambios (WriteOut).

Ctrl + X: Sale del editor.
(Si hiciste modificaciones sin guardar previamente, Nano te preguntará si deseas guardarlas: presiona Y para sí, N para no, y luego Enter).

3. Entornos Gráficos (Gedit, Kate, VS Code)
Funciona igual que en otros sistemas operativos:

Ctrl + S: Guarda el archivo.

Ctrl + W o Alt + F4: Cierra la ventana o pestaña activa.
