## Insertar texto 
es la acción de agregar nuevos caracteres, palabras o bloques de contenido dentro de un punto específico de un documento o archivo sin sobrescribir el texto existente.

En Linux, la forma de insertar texto varía según el editor o método que utilices:

1. En la Terminal con el editor Vim
En Vim existe una distinción clave entre el modo de comandos y el modo de inserción:

Presiona i: Entra al modo de inserción e inserta texto antes del cursor.

Presiona a: Entra al modo de inserción e inserta texto después del cursor (anexar).

Presiona o: Abre una nueva línea debajo del cursor e ingresa al modo de inserción.

Presiona Esc: Sal del modo de inserción para volver al modo normal.
